Modification by the NEXUS project:
The Maven tasks-core 0.10.35 AAR enables the TasksStatsProtoLogger usage-logging
factory. NEXUS replaces ONLY TasksStatsLoggerFactory.class with the no-op
TasksStatsDummyLogger factory generated by the upstream BUILD by default when
its internal ENABLE_TASKS_USAGE_LOGGING flag is not enabled.

This is a transparent derivative, not an unmodified Google Maven artifact.
No runtime reflection, hidden activation, security-detector workaround, or
modification of the native libraries is used. All other JAR/AAR entry payloads
remain byte-identical to the pinned Maven distribution. Remote logger classes
and their dependencies remain present but are not selected by the factory.

The source, input hashes, deterministic preparation and verification tests are
in scripts/prepare_mediapipe_runtime.py and scripts/mediapipe/. Preparation emits
an adjacent .provenance.json containing the output hash and all native hashes.
