# Ícones usados pelo NEXUS

Este diretório conserva somente os 22 vetores Filled utilizados que pertenciam a `material-icons-extended` 1.7.8. Os cinco ícones Filled básicos e ArrowBack/Send AutoMirrored continuam no pacote pequeno `material-icons-core`.

Os arquivos Kotlin vieram do sources JAR oficial AndroidX, com tamanho e SHA-256 conferidos contra os metadados Gradle oficiais. Apenas o pacote Kotlin foi alterado; desenhos, dimensões, comportamento, anotação e avisos Apache 2.0 foram preservados. `PROVENANCE.json` registra cada hash original e local. Nenhum vetor substituto foi desenhado.
